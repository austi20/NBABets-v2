# Documentation Archive

This directory holds completed handoffs, old implementation outlines, and
historical incident/program material that should remain searchable but should
not be treated as active project direction.

- `full-review/` - old full-project review governance, incident boards, closeout, and runbooks.
- `active-trader/` - completed active-trader handoff notes.
- `performance/` - completed/deferred performance optimization outline.
- `rotation-shock/` - original implementation plan now superseded by `docs/rotation_shock_architecture.md`.
- `superpowers/` - historical Superpowers specs and plans.
